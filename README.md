# ReachNYC

ReachNYC helps kids in NYC find free STEM programs near them.

You tell it where you live, what grade you're in, and what you like. It shows you programs you can join, how to get there by subway, and when to apply.

It works in English, Spanish, Russian and Urdu.

## How to open it

Double-click `index.html`.

## How to run the tests

Open `subway/pom.xml` in IntelliJ and run the tests in `subway/src/test`.
